# Task 60 — Scelta della domanda a sorpresa e script di invio a ntfy

Target: claude

## Goal
Scrivere la scelta della domanda e lo script di invio della feature `domanda-a-sorpresa`: dai file di `contenuti/lezioni/` sceglie un vocabolo, compone la notifica e la pubblica su `https://ntfy.sh/<canale>`.

## Acceptance criteria
- La scelta pesa 3 i vocaboli delle tre lezioni più recenti e 1 gli altri, uniforme a parità di peso, con la casualità come parametro.
- La notifica ha titolo `maies`, testo `Come si dice «<it>»?`, indirizzo `https://maies.chosko.com/#/vocaboli?parola=<id globale codificato>` e un'etichetta con l'icona a fumetto.
- Lo script legge il canale da `NTFY_TOPIC`; senza canale o senza vocaboli non pubblica e termina senza errore, scrivendo il motivo; un errore di ntfy.sh lo fa terminare con errore; il canale non compare mai nel log.
- Nessuna dipendenza nuova; uno script npm `domanda-a-sorpresa` lo esegue; i test coprono scelta, testo, indirizzo e i casi senza canale e con errore (con `fetch` sostituito).

## Decisions
- Lo script è un modulo Node in JavaScript che esporta le funzioni pure e le esegue solo se lanciato direttamente: gira nella GitHub Action senza compilazione e Vitest lo importa.
