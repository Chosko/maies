# Task 62 — Attivare la domanda a sorpresa sul telefono di Sara

Target: human

## Goal
Attivare le notifiche della feature `domanda-a-sorpresa`: creare il segreto del canale nel repository e iscrivere il telefono di Sara al canale nell'app ntfy, poi verificare con un'esecuzione manuale.

## Acceptance criteria
- Il file `.github/workflows/domanda-a-sorpresa.yml` esiste sul branch principale, copiato dal modello.
- Il segreto `NTFY_TOPIC` esiste nel repository.
- Il telefono di Sara è iscritto al canale sul server `ntfy.sh` nell'app ntfy.
- Un'esecuzione manuale del workflow fa arrivare la notifica, e toccandola si apre maies sulla parola.

## Decisions
- Il workflow deve essere sul branch principale: GitHub esegue solo da lì i workflow pianificati e manuali, quindi l'attivazione segue il merge.

## Manual interventions
⚠ Questo task richiede una persona: nessun passo è eseguibile da un agente.

0. **Dopo il merge sul branch principale** — dalla pagina web del repository (Add file → Create new file) creare `.github/workflows/domanda-a-sorpresa.yml` incollando il contenuto di `scripts/domanda-a-sorpresa.workflow.yml`, e fare commit su `main`. Esito: il workflow "Domanda a sorpresa" compare nella scheda Actions.
1. **Segreto** — nelle impostazioni del repository GitHub (Settings → Secrets and variables → Actions) creare il segreto `NTFY_TOPIC` con un nome di canale lungo e casuale, per esempio quello proposto in chat. Esito: il segreto compare nell'elenco.
2. **Sul telefono di Sara** — installare l'app ntfy (App Store o Google Play), toccare "+", inserire lo stesso nome di canale sul server `ntfy.sh` e consentire le notifiche. Esito: il canale compare nell'app.
3. **Verifica** — nella scheda Actions del repository avviare a mano "Domanda a sorpresa". Esito: entro un minuto arriva la notifica "Come si dice «…»?", e toccandola si apre maies su quella parola.
