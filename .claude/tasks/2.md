# Task 2 — Stile di base generato dai token del design

Target: claude

## Goal
Secondo passo della feature `scheletro-e-pubblicazione`: lo stile di base
dell'app. Ogni token di `design/tokens.json` diventa una variabile CSS
generata dal file, il carattere è Poppins, il CSS è scritto mobile-first con
un solo punto di passaggio tra telefono e computer, e gli elementi comuni di
`design/design-system.md` (fondo con bagliore e bandiera a linee, carte,
bottoni, campi, cerchi icona) sono pronti perché le schermate future li
riusino.

## Acceptance criteria
- Ogni token di colore, tipografia, spazio e raggio di `design/tokens.json`
  ha una variabile CSS su `:root` con il valore del file, prodotta leggendo il
  file e non trascritta a mano: sostituire `design/tokens.json` con una copia
  nuova aggiorna lo stile senza altre modifiche.
- Un test Vitest verifica che ogni token del file abbia la sua variabile con
  il suo valore.
- Colori, caratteri, spazi e raggi negli stili vengono solo da quelle
  variabili, mai da valori scritti a mano.
- Poppins è caricato da Google Fonts (pesi 400, 500, 600) con `system-ui`
  come ripiego.
- Il CSS è mobile-first con un solo punto di passaggio al layout computer,
  dichiarato in un solo posto.
- Esistono classi o componenti riusabili per: il fondo con il bagliore
  (più largo e basso su computer) e la bandiera a linee dietro la metà bassa,
  la carta, il bottone principale e quello secondario, il campo di testo e il
  cerchio icona, con le misure di `design/design-system.md`; dove testo e
  schermate in `design/schermate/` non coincidono, valgono le schermate.
- Le schermate segnaposto del task 1 stanno sul fondo e in una carta.
  `npm test`, `npm run typecheck` e `npm run build` riescono.

## Decisions
- **Il punto di passaggio è 768px**: il design non ne indica uno e non è un
  token; è dichiarato una volta sola, così cambiarlo è un'unica modifica.
- **Il modo di generare le variabili è libero** (un modulo TypeScript che
  importa il JSON, o un plugin di Vite), purché legga `design/tokens.json` e
  il test lo verifichi.
